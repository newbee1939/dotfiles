# Plan Tomorrow（明日のタスク計画）

**朝、迷いゼロで即着手できる状態**を前日のうちに作る。Linear の操作は Linear MCP のツール（`mcp__linear*`）を使う。

## 手順
1. **材料を集める**
   - Linear: 自分アサインの未完了チケット（ステータス / 優先度 / 期日 / 見積もり）
   - 各チケットの中身: 説明のタスクリスト、直近コメント、関連 PR のリンク
   - PR: `gh pr status`、`gh pr list --author @me --state open`（レビュー待ち / 変更要求 / CI 失敗を見る）
2. **チケットごとに「次の 1 手」を 1 行で書く**（例:「レビュー指摘 3 件を反映して再レビュー依頼」）。
3. **並べる**。上から優先:
   1. 他人をブロックしているもの（レビュー返し、承認済み PR のマージ）— 短時間で他人が動ける
   2. 期日が近い / 優先度 Urgent・High
   3. 着手済み（In Progress）を終わらせる — 仕掛かりを増やさない
   4. 新規着手
4. **8 時間に積む**。各タスクに所要時間を割り当て、**合計 6 時間で打ち止め**（残り 2 時間は割り込み・MTG・レビュー用のバッファ）。最も重い 1 件を朝イチに置く。
5. **出力する**（下記フォーマット）。

## 出力フォーマット
```
## 明日やること（YYYY-MM-DD）
| 順 | 時間 | チケット | やること | 完了条件 |

## 朝会で話すこと
- 昨日: <1〜2 行>
- 今日: <1〜2 行>
- 困っていること: <なければ「なし」>

## 今日はやらない
- <チケット> — <理由>
```

## 原則
- 「〜を進める」は書かない。**完了したか判定できる粒度**にする。
- 全部を積まない。溢れたものは「やらない」に明示して、朝に迷う余地を消す。
