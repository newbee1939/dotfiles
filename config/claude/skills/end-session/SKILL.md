# End Session（セッション終了・Linear 更新）

セッションの終わりに **Linear の対象チケットを最新化**し、次回すぐ再開できる状態にする。
Linear の操作は Linear MCP のツール（`mcp__linear*`）を使う。

## 手順
1. **対象チケットを特定する**。ブランチ名・直近の会話から推定し、曖昧なら自分の未完了チケットを一覧して確認する。
2. **このセッションでやったことを集める**: `git log --oneline --since=midnight`、`gh pr view`（あれば）、Slack の自分の投稿（`mcp__slack*`）、会話の要点。
3. **コメントを 1 件追記する**（日本語・5 行以内）:
   - やったこと
   - 現状（PR の状態、詰まっている点）
   - **次回やること = 再開ポイント**
4. **チケット本文のタスクリストを更新する**。実際に完了したものだけ `- [ ]` → `- [x]`。
5. 状況が変わっていれば**ステータスを更新**する（In Progress / In Review など）。
6. 更新したチケットの **URL を提示**する。

## 原則
- 憶測で完了にしない。**git ログ・PR・Slack の自分の投稿**で確認できたものだけチェックする。
- コメントは「翌朝の自分が読んで 5 秒で再開できる」粒度にする。長い経緯は書かない。
- 1 セッション 1 コメント。細かく分けない。
