# Daily Plan（今日やったこと・明日やること）

**退勤前**に実行し、**今日やったこと**と**明日やること**を 1 枚にまとめる。翌朝はこれを読むだけで着手できる状態にする。

## 1. 材料を集める（今日 00:00 以降）
- **Linear**（`mcp__linear*`）: 自分アサインのチケット。ステータス / 優先度 / 期日、説明のタスクリスト、直近コメント
- **PR**: チケットに紐づく PR の状態（レビュー待ち / 変更要求 / CI 失敗）。チケット外の分は `gh pr status` で拾う
- **コミット**: `git log --author="$(git config user.email)" --since=midnight --oneline`
- **Slack**（`mcp__slack*`）: 今日の自分の投稿。**チケットになっていない依頼や約束**が出てくるので必ず見る
- 会話から、コード以外の作業（調査・設計・対応）も拾う

## 2. 明日やることを並べる
上から優先:
1. **他人を待たせているもの**（レビュー返し、承認済み PR のマージ、Slack で聞かれたまま返していないもの）
2. 期日が近い / 優先度が高い
3. 着手済みのものを終わらせる（仕掛かりを増やさない）
4. 新規着手

各タスクに所要時間を振り、**合計 6 時間で打ち止め**（残りは割り込みと MTG のバッファ）。一番重いものを朝イチに置く。

## 3. 出力
```
## 今日やったこと
- <チケット / PR>: <やったこと> → <今の状態>

## 明日やること
| 順 | 時間 | チケット | やること | 完了条件 |

## 明日はやらない
- <チケット> — <理由>
```

## 原則
- 「〜を進める」は書かない。**完了したか判定できる粒度**にする。
- 今日やったことは、ログ・PR・Slack で確認できたものだけ書く。記憶で補完しない。
- 溢れたものは「やらない」に明示して、迷う余地を消す。
