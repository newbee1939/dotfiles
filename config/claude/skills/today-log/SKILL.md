# Today Log（今日やったことの一覧）

翌朝の朝会で**そのまま読める**形に今日の作業をまとめる。

## 手順
1. **集める**（すべて今日 00:00 以降）
   - コミット: `git log --author="$(git config user.email)" --since=midnight --oneline`（関係するリポジトリごとに）
   - PR: `gh search prs --author=@me --updated=">=$(date +%F)"`
   - レビュー: `gh search prs --reviewed-by=@me --updated=">=$(date +%F)"`
   - Linear: 今日更新した自分のチケットとコメント（Linear MCP のツール `mcp__linear*`）
   - 会話から、コード以外の作業（調査・設計・対応・打ち合わせ）も拾う
2. **「何が前に進んだか」でまとめる**。コミット数やファイル名の羅列にしない。
3. **出力する**（下記フォーマット）。

## 出力フォーマット
```
## 今日やったこと（YYYY-MM-DD）
- <チケット / PR>: <やったこと> → <今の状態>

## 持ち越し
- <チケット>: <残っていること>

## 詰まっていること
- <なければ「なし」>
```

## 原則
- 一行一件。装飾しない。
- ログや PR で**確認できたものだけ**書く。記憶で補完しない。
